# Huckline — app builds

Build shell for **Huckline**, a big-mountain freeride bike game. This repository holds only the
compiled web bundle (`dist/`), the native Android and iOS shells, the CI workflows and the website
(`docs/`, served by GitHub Pages). The game's source code is private.

- Latest Android APK: https://github.com/Mulhimfy/huckline-app/releases/latest/download/Huckline.apk
- Website and privacy policy: https://mulhimfy.github.io/huckline-app/
